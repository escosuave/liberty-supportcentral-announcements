# Quick Start: 10-Minute Changes
**Emergency workflow when Cursor/local tools are slow or unavailable**

---

## 🚀 Fastest Path (GitHub Web Interface)

### Option 1: Quick Edit (5-10 minutes)
1. **Go to:** https://github.com/escosuave/liberty-supportcentral-announcements
2. **Click file:** `announcements-us.html` or `announcements-ca.html`
3. **Click pencil icon** (✏️) to edit
4. **Make changes** (use templates in `.github/` folder)
5. **Commit directly to main** (no PR needed)
6. **Wait 2-5 minutes** → Verify on help center

**Full guide:** See `GITHUB_QUICK_EDIT_GUIDE.md`

---

## 📋 Templates Available

- **New Banner:** `.github/TEMPLATE_NEW_BANNER.md`
- **Archive Entry:** `.github/TEMPLATE_ARCHIVE_ENTRY.md`

## ✅ Checklist

Before committing:
- [ ] HTML syntax is valid
- [ ] Link URL is correct (US vs CA domain)
- [ ] Priority number is appropriate
- [ ] Tracking comment is complete
- [ ] If removing: Archived first

After committing:
- [ ] Wait 2-5 minutes
- [ ] Visit help center
- [ ] Hard refresh (Ctrl+F5)
- [ ] Verify banner appears
- [ ] Test link works
- [ ] Update tracking in README.md
