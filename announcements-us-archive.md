## Archive Guidelines

When removing an announcement:
1. Copy the full HTML block (including comments) to this archive
2. Add metadata (date removed, reason)
3. Include the display text for quick reference
4. Maintain chronological order (newest removals at top)

**Common Removal Reasons:**
- Expired deadline
- Issue resolved
- Information outdated
- Replaced by newer announcement
- End of maintenance window
